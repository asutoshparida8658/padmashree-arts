# Padmashree Arts

Next.js (App Router) + TypeScript + Tailwind + Framer Motion. Static export.

## Run
npm install
npm run dev

## Edit content
All text, categories and products are in `data/site.ts`.
Product photos are in `public/products/`. Artist photo is `public/artist.jpg`; artist text is in `data/site.ts`.

## Deploy (Cloudflare Pages, free)
1. Push to GitHub.
2. Cloudflare Pages -> Create project -> connect repo.
3. Build command: `npm run build`   Output directory: `out`
